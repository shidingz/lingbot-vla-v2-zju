四、让现有部署入口找到配置（避免拷贝第二份大权重）
假设已下载到上述绝对路径，且 LingBot 项目代码和 RoboTwin 环境已安装。
以下命令使用一个独立的新评测工作目录，避免覆盖已有实验：

export MODEL_ROOT=/data/models/lingbot-vla-v2-robotwin-1ep-npu
export EVAL_RUN=/data/eval_runs/robotwin_1ep_5717
export LINGBOT_REPO=/path/to/lingbot-vla-v2
mkdir -p "$EVAL_RUN/checkpoints/global_step_5717"
cp "$MODEL_ROOT/inference_assets/lingbotvla_cli.yaml" "$EVAL_RUN/lingbotvla_cli.yaml"
ln -s "$MODEL_ROOT" "$EVAL_RUN/checkpoints/global_step_5717/hf_ckpt"
export QWEN3VL_PATH="$MODEL_ROOT/inference_assets/Qwen3-VL-4B-Instruct"

关键：MODEL_ROOT、EVAL_RUN 使用绝对路径；这里软链接指向完整仓库下载根目录。
部署入口按传入路径的上三级寻找 lingbotvla_cli.yaml，不能只把模型根目录直接传给 --model_path。
不要将该软链接 resolve 后的真实路径作为 --model_path，否则上三级又变成下载路径的祖先目录。
目标最终目录结构：
  EVAL_RUN/lingbotvla_cli.yaml
  EVAL_RUN/checkpoints/global_step_5717/hf_ckpt -> MODEL_ROOT

五、推理启动和 randomized 评测参数
单服务启动示例（先做一次动作输出冒烟检查，再跑全任务）：

cd "$LINGBOT_REPO"
python -m deploy.lingbot_vla_v2_policy \
  --model_path "$EVAL_RUN/checkpoints/global_step_5717/hf_ckpt" \
  --use_length 50 --use_bf16 True --use_fp32 False --use_compile False --port 9330

BF16、关闭 compile 是首轮兼容性/吞吐检查设置，不代表已验证与 FP32 成功率一致。
若严格对齐项目默认发布评测精度，使用 --use_bf16 False --use_fp32 True，并按显存调整并发。
当前 checkpoint 配置 num_steps=10、chunk_size=50；CLI 的 use_length=50 为动作块执行长度。
训练在 Ascend NPU 完成，但 safetensors 是设备无关权重格式。其他机器仍需与代码兼容的 PyTorch/Transformers、注意力和 MoE 算子环境。

NVIDIA/CUDA 队友使用项目联合评测脚本的示例（填写实际环境路径）：

bash experiment/robotwin/start_robotwin_infer_and_eval.sh \
  --model_path "$EVAL_RUN/checkpoints/global_step_5717/hf_ckpt" \
  --inference_workdir "$LINGBOT_REPO/" \
  --eval_workdir /path/to/RoboTwin \
  --conda_sh /path/to/miniconda3/etc/profile.d/conda.sh \
  --inference_env lingbotvla --sim_env RoboTwin \
  --output_base /data/eval_results \
  --task_config demo_randomized \
  --num_tasks 1 --num_gpus 1 --num_per_gpu 1 \
  --use_length 50 --use_bf16 True --use_fp32 False --use_compile False --no_video

先单任务确认后，把 --num_tasks 改为 50，再按资源提升并发。
务必显式 --task_config demo_randomized；脚本默认是 demo_clean。
该联合脚本针对 CUDA GPU，不能原样宣称在 Ascend 上可启动 RoboTwin 仿真。
推荐在所有对比模型中固定精度、10 个去噪步骤、动作执行长度、任务清单、种子与 episode 数。
